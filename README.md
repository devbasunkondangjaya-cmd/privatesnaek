# Venomcoil ? Flutter + Flame

Game Flutter dengan Flame, berisi 20 area, HUD, checkpoint, musuh, dan kemampuan coil, venom, serta tail whip. Konfigurasi area ada di `lib/level_data.dart`; gambar dan audio ada di `assets/`. Game tidak memerlukan JavaScript atau aset JSON.

## Menjalankan

```sh
flutter pub get
flutter run
```
